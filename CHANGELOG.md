# Changelog

Все заметные изменения проекта записываются здесь. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии — [Semantic Versioning](https://semver.org/lang/ru/). Коммиты оформляются по [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/): одна смысловая правка на коммит.

Каждый выпуск готовится в ветке `release/x.y.z`, получает тег `vx.y.z` и запись ниже. Релизная ветка сливается в актуальный `main`; после каждого выпуска GitHub Actions проверяет и публикует сайт в GitHub Pages.

## [Unreleased]

## [1.22.0] - 2026-10-03

### Added

- В minmax можно выбрать City Walk вечером, Sky Views утром или только Dubai Mall с фонтанами. Предпросмотр показывает возвращение и расходы; перегруженное сочетание нельзя применить.
- Выбор остановки для перерыва на еду. Перерыв остаётся у выбранного места при оптимизации порядка и сохраняется в копии плана; при удалении места переносится в середину маршрута.

### Changed

- На Dubai Mall по умолчанию выделено шесть часов. Дорога, еда, очереди и дополнительные платные развлечения считаются отдельно; время в молле не урезается ради дополнений.
- Готовый Downtown-день больше не обещает одновременно молл, подъём на башню, платный аквариум и фонтаны. Базовый вариант — полноценный молл и фонтаны, остальные места выбираются отдельно.

## [1.21.0] - 2026-10-03

### Added

- Trip.com в сравнении билетов для AYA, The View, Aquaventure, Рамки и двух садов: ссылки ведут на конкретные пакеты или страницу самого места.
- Проверенные рублёвые цены трёх пакетов на 6 октября, дата проверки и ограничения рядом с предложением: детский тариф, часы входа, возврат и получение ваучера. Старые скидки из поиска не выдаются за действующие цены.
- У сезонных и непроверенных пакетов цена остаётся неподтверждённой; экскурсии с трансфером не сравниваются с обычным входом как одинаковые билеты.

## [1.20.0] - 2026-10-03

### Added

- «Перед выездом» в плане дня: фотографии платных мест, стоимость выбранного состава, время входа и переход к сравнению билетов.
- Покупки отмечаются отдельно для каждой семьи. При изменении состава, возраста ребёнка или времени входа сайт просит перепроверить подходящие билеты; заданное время не считается покупкой.
- Отметки сохраняются с датой в плане, передаются в файле и ссылке и видны в дорожном листе для печати. Чужой снимок плана остаётся доступным только для чтения до сохранения копии.

## [1.19.0] - 2026-10-03

### Added

- При добавлении места проверяются все позиции в маршруте. Дневная прогулка может попасть перед вечерним шоу: порядок остальных остановок, длительности, очереди, отдых и время билетов сохраняются.
- Карточки выбора и быстрый выбор дня заранее показывают положение остановки. Фильтр «Помещается в день» и рекомендации используют тот же расчёт, что и добавление в план.

## [1.18.0] - 2026-10-03

### Added

- Скачивание плана в JSON для резервной копии и переноса на другое устройство: места, даты, время входа, посещения, очереди и транспортные настройки сохраняются вместе.
- Восстановление сначала показывает дни и места из файла, сравнивает число остановок с текущим планом и позволяет отменить замену. Загрузка сама по себе не меняет план.
- Повреждённые файлы, чужие направления, неподдерживаемые версии и полностью неподходящие даты отклоняются. Частично устаревшие копии показывают число пропущенных остановок; фотографии и избранное сохраняются отдельно.

## [1.17.0] - 2026-10-03

### Added
